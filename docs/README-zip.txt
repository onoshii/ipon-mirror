Ipon Mirror
===========

iPhone の画面を無線 (AirPlay) で Windows に映すアプリです。

■ 使い方
  1. IponMirror.exe を起動
     (初回は Windows のファイアウォール確認が出ることがあります。許可してください)
  2. iPhone を PC と同じ Wi-Fi / ルーターにつなぐ
  3. iPhone のコントロールセンター → 「画面ミラーリング」 → 「Ipon Mirror」

■ 映像ウィンドウ
  ドラッグ: 移動 / ホイール: 拡大縮小 / ダブルクリック: 全画面 (Escで戻る)
  R: 映像を回転 (カメラなど) / ↑↓: 音量 / M: ミュート / 右クリック: メニュー / 右上の ✕: ミラーリング終了
  (音量はメイン画面のスライダーでも調節できます)

■ うまくいかないとき
  ・PC と iPhone が同じネットワークか確認 (ゲスト Wi-Fi は不可)
  ・他の AirPlay 受信アプリを閉じる
  ・ログ: %LOCALAPPDATA%\IponMirror\engine.log
